# THE CELESTIAL : PROJECT — เว็บไซต์คอมมูนิตี้ + ระบบหลังบ้าน

เว็บไซต์ Idol Survival Role-Play แยกหน้าครบทุกส่วน พร้อมระบบหลังบ้านให้สตาฟ และระบบโหวตแฟนคลับ (ต้องล็อกอิน โหวตได้วันละ 1 ครั้ง)
หน้าเว็บเป็นไฟล์ HTML ธรรมดา วางบน **GitHub Pages** ได้ฟรี ส่วนฐานข้อมูลใช้ **Google Sheets + Google Apps Script** (ฟรีเช่นกัน)

## 2. ลองใช้ทันที (โหมดตัวอย่าง)

ถ้ายังไม่ได้ตั้งค่า `API_URL` เว็บจะทำงานใน **โหมดตัวอย่าง**: ใช้ข้อมูลสมมติ และทุกการแก้ไข/โหวตจะเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น
- เข้าหลังบ้าน: `admin.html` → ชื่อผู้ใช้ `polaris` (แอดมิน) หรือ `sirius` (สตาฟ) รหัสผ่าน `celestial2570`
- ใช้ทดสอบหน้าตาและการทำงานได้ครบ แต่ **ห้ามใช้จริง** เพราะข้อมูลไม่ถูกแชร์ระหว่างเครื่อง

## 3. ตั้งค่าฐานข้อมูล (Google Sheets + Apps Script) — ทำครั้งเดียว ~10 นาที

1. เปิด [Google Sheets](https://sheets.google.com) สร้างชีตใหม่ ตั้งชื่อเช่น `Celestial Database`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางเนื้อหาจาก `backend/Code.gs` ทั้งหมด
4. (ไม่บังคับ) อยากได้ข้อมูลตัวอย่างไว้ดูโครงสร้าง: กด **+ → Script** ตั้งชื่อ `Seed` แล้ววางเนื้อหา `backend/Seed.gs`
5. เลือกฟังก์ชัน **`setup`** ที่แถบด้านบน แล้วกด **Run** → กดอนุญาตสิทธิ์ (Review permissions → เลือกบัญชี → Advanced → Go to … → Allow)
6. ดู **Execution log** ด้านล่าง จะมี **ชื่อผู้ใช้ `admin` และรหัสผ่าน** ของแอดมิน — จดไว้
7. (ถ้าทำข้อ 4) เลือกฟังก์ชัน **`loadSampleData`** แล้วกด Run
8. กด **Deploy → New deployment** → ไอคอนเฟือง เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
9. เปิดไฟล์ `js/config.js` แล้ววาง URL:
   ```js
   API_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
   ```

> ⚠️ ทุกครั้งที่แก้ `Code.gs` ต้องไปที่ **Deploy → Manage deployments → ✎ Edit → Version: New version → Deploy** ไม่อย่างนั้นเว็บยังใช้โค้ดเก่า (URL เดิมใช้ต่อได้)

ในชีตจะมีแท็บ `trainees`, `banners`, `events` ฯลฯ ทีมงานแก้ผ่านหลังบ้านได้ทั้งหมด ไม่จำเป็นต้องแก้ชีตเอง
ถ้าแก้ชีตด้วยมือ ให้ใช้เมนู **✦ Celestial → ล้างแคชหน้าเว็บ** ในชีต เพื่อให้หน้าเว็บอัปเดตทันที

## 4. ขึ้นเว็บด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub (Public) เช่น `celestial-project`
2. **Add file → Upload files** ลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (`index.html`, `css/`, `js/`, `assets/` …) แล้ว Commit
3. **Settings → Pages → Branch: `main` / root → Save**
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/celestial-project/`

## 5. ใช้งานระบบหลังบ้าน (`admin.html`)

1. เข้าด้วยบัญชี `admin` → กดปุ่ม **รหัสผ่าน** มุมขวาบนเพื่อเปลี่ยนรหัสผ่านทันที
2. ไปที่ **บัญชีทีมงาน → + เพิ่มบัญชี** สร้างให้สตาฟทั้ง 8 คน (คนละบัญชี) เลือกสิทธิ์
   - หรือตั้งบัญชีแบบรู้กันเองใน `Code.gs`: แก้รายการ `STAFF_LOGINS` ด้านบนไฟล์ (ชื่อผู้ใช้ / รหัสผ่านอย่างน้อย 8 ตัว / role) แล้วเลือกฟังก์ชัน **`setStaffLogin`** กด Run หรือใช้เมนู ✦ Celestial → ตั้งบัญชีสตาฟตาม STAFF_LOGINS (เปลี่ยนรหัสแล้วรันใหม่ได้ ไม่ต้อง Deploy ใหม่) — ใส่รหัสจริงเฉพาะในหน้า Apps Script เท่านั้น ไฟล์ `backend/Code.gs` ในโฟลเดอร์นี้เว้นรหัสไว้ว่าง
   - **สตาฟ**: แก้เนื้อหาทุกอย่าง อัปเดตอันดับ เทียร์ สถานะ แบนเนอร์ ปฏิทิน ระงับแฟนคลับ
   - **แอดมิน**: ทำได้ทุกอย่าง + จัดการบัญชีทีมงาน + รีเซ็ตคะแนนโหวต
3. ทุกการแก้ไขถูกบันทึกในเมนู **บันทึกการทำงาน** ว่าใครแก้อะไรเมื่อไร

งานที่ทำบ่อย:
- **อัปเดตอันดับ**: เมนู “อันดับเด็กฝึก” → เลือกรอบ → ลากเรียง (หรือกด “เรียงตามผลโหวต”) → ตั้งเส้นตัด → **บันทึกอันดับ**
- **เปลี่ยนสถานะเด็กฝึก** (ตกรอบ/ถอนตัว/เดบิวต์): เมนู “เด็กฝึก” เลือกจากช่องสถานะในแต่ละแถว
- **เพิ่มแบนเนอร์**: เมนู “แบนเนอร์” → อัปโหลดรูป 2100×800 (หรือไม่ใส่รูป ระบบสร้างแบนเนอร์ลายดวงจันทร์ให้)
- **เปิด/ปิดโหวต**: แดชบอร์ด หรือเมนู “ระบบโหวต” — เมื่อเริ่มรอบใหม่ ให้เปลี่ยน “นับคะแนนเข้ารอบ” คะแนนจะเริ่มนับใหม่โดยไม่ลบของเก่า
- **ประกาศ popup**: “ตั้งค่าเว็บไซต์ → ประกาศ popup หน้าแรก” (แก้ข้อความแล้วจะเด้งให้ทุกคนเห็นใหม่)

## 6. รูปภาพและไฟล์เสียง

- กด **อัปโหลด** ในหลังบ้านได้เลย ไฟล์จะไปอยู่ใน Google Drive โฟลเดอร์ `Celestial Uploads` และเปิดแชร์ให้หน้าเว็บแสดงผลอัตโนมัติ
- หรือวางลิงก์รูปจากที่อื่น รวมถึงลิงก์แชร์ Google Drive (`https://drive.google.com/file/d/…/view`) ระบบแปลงให้เอง — ไฟล์ต้องตั้งค่าแชร์เป็น **ทุกคนที่มีลิงก์**
- เพลงในเพลย์ลิสต์: ใช้ไฟล์ `.mp3` ใน Google Drive (แชร์ทุกคนที่มีลิงก์) หรือใส่ลิงก์ YouTube
- ขนาดรูปแนะนำ: โปรไฟล์เด็กฝึก 4:5 (เช่น 800×1000), แบนเนอร์ 21:8, ปกเพลง/ทีมงาน สี่เหลี่ยมจัตุรัส

## 7. ระบบโหวตทำงานอย่างไร

- แฟนคลับต้องสมัครบัญชี (ชื่อผู้ใช้ + รหัสผ่าน) ที่ `login.html`
- 1 บัญชีโหวตได้ **วันละ 1 ครั้ง** เลือกเด็กฝึก 1 คน ระบบตัดรอบ **00:00 น. เวลาประเทศไทย** และตรวจสอบที่เซิร์ฟเวอร์ (แก้โค้ดฝั่งเบราว์เซอร์ก็โหวตซ้ำไม่ได้)
- รหัสผ่านเก็บแบบเข้ารหัสทางเดียว (hash + salt) ทีมงานมองไม่เห็นรหัสผ่านของใคร
- ล็อกอินผิดเกิน 8 ครั้ง บัญชีนั้นจะถูกพักการล็อกอิน 15 นาที
- ข้อจำกัด: ระบบป้องกันคนเดียวสร้างหลายบัญชีไม่ได้ 100% ทีมงานใช้เมนู **แฟนคลับ** ตรวจบัญชีที่ผิดปกติและกด **ระงับ** ได้
