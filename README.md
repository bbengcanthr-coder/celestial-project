เว็บไซต์ Idol Survival Role-Play แยกหน้าครบทุกส่วน พร้อมระบบหลังบ้านให้สตาฟ และระบบโหวตแฟนคลับ (ต้องล็อกอิน โหวตได้วันละ 1 ครั้ง)

## 2. ลองใช้ทันที (โหมดตัวอย่าง)

ถ้ายังไม่ได้ตั้งค่า `API_URL` เว็บจะทำงานใน **โหมดตัวอย่าง**: ใช้ข้อมูลสมมติ และทุกการแก้ไข/โหวตจะเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น
- เข้าหลังบ้าน: `admin.html` → ชื่อผู้ใช้ `polaris` (แอดมิน) หรือ `sirius` (สตาฟ) รหัสผ่าน `celestial2570`
- ใช้ทดสอบหน้าตาและการทำงานได้ครบ แต่ **ห้ามใช้จริง** เพราะข้อมูลไม่ถูกแชร์ระหว่างเครื่อง

## 3. ตั้งค่าฐานข้อมูล (Google Sheets + Apps Script) — ทำครั้งเดียว ~10 นาที

1. เปิด [Google Sheets](https://sheets.google.com) สร้างชีตใหม่ ตั้งชื่อเช่น `Celestial Database`
2. เมนู **ส่วนขยาย (Extensions) → Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางเนื้อหาจาก `backend/Code.gs` ทั้งหมด
4. (ไม่บังคับ) อยากได้ข้อมูลตัวอย่างไว้ดูโครงสร้าง: กด **+ → Script** ตั้งชื่อ `Seed` แล้ววางเนื้อหา `backend/Seed.gs`
5. เลือกฟังก์ชัน **`setup`** ที่แถบด้านบน แล้วกด **Run** → กดอนุญาตสิทธิ์ (Review permissions → เลือกบัญชี → Advanced → Go to … → Allow)
6. ดู **Execution log** ด้านล่าง จะมี **ชื่อผู้ใช้ `admin` และรหัสผ่าน** ของแอดมิน — จดไว้
7. (ถ้าทำข้อ 4) เลือกฟังก์ชัน **`loadSampleData`** แล้วกด Run
8. กด **Deploy → New deployment** → ไอคอนเฟือง เลือก **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)
9. เปิดไฟล์ `js/config.js` แล้ววาง URL:
   ```js
   API_URL: "https://script.google.com/macros/s/xxxxxxxx/exec",
   ```

> ⚠️ ทุกครั้งที่แก้ `Code.gs` ต้องไปที่ **Deploy → Manage deployments → ✎ Edit → Version: New version → Deploy** ไม่อย่างนั้นเว็บยังใช้โค้ดเก่า (URL เดิมใช้ต่อได้)

ในชีตจะมีแท็บ `trainees`, `banners`, `events` ฯลฯ ทีมงานแก้ผ่านหลังบ้านได้ทั้งหมด ไม่จำเป็นต้องแก้ชีตเอง
ถ้าแก้ชีตด้วยมือ ให้ใช้เมนู **✦ Celestial → ล้างแคชหน้าเว็บ** ในชีต เพื่อให้หน้าเว็บอัปเดตทันที

## 3.1 อัปเดตจากเวอร์ชันก่อน (มีข้อมูลจริงอยู่แล้ว)

1. Apps Script → ลบโค้ดเดิมใน `Code.gs` แล้ววาง `backend/Code.gs` ใหม่ทั้งไฟล์ (อย่าลืมใส่รหัสใน `STAFF_LOGINS` ใหม่ถ้าเคยใช้)
2. เลือกฟังก์ชัน **`setup`** → Run อีกครั้ง — **ไม่ลบข้อมูลเดิม** แค่เติมแท็บใหม่ (`voteboard`, `hearts`) คอลัมน์ใหม่ของแท็บ `fans` และค่าเริ่มต้นระดับแฟนคลับ
3. **Deploy → Manage deployments → ✎ Edit → Version: New version → Deploy** (URL เดิมใช้ต่อได้)
4. อัปโหลดไฟล์หน้าเว็บทั้งหมดขึ้น GitHub ทับของเดิม (มีไฟล์ใหม่ `profile.html`, `fanclub.html`, `js/galaxy.js`, `js/pages/profile.js`, `js/pages/fanclub.js`)
5. ตั้งแต่เวอร์ชันนี้ ผลโหวตจะไม่โชว์บนหน้าเว็บอีก จนกว่าทีมงานจะกด “ประกาศผล” ในหลังบ้าน (ดูข้อ 7)

## 4. ขึ้นเว็บด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub (Public) เช่น `celestial-project`
2. **Add file → Upload files** ลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (`index.html`, `css/`, `js/`, `assets/` …) แล้ว Commit

4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://ชื่อผู้ใช้.github.io/celestial-project/`

## 5. ใช้งานระบบหลังบ้าน (`admin.html`)

1. เข้าด้วยบัญชี `admin` → กดปุ่ม **รหัสผ่าน** มุมขวาบนเพื่อเปลี่ยนรหัสผ่านทันที
2. ไปที่ **บัญชีทีมงาน → + เพิ่มบัญชี** สร้างให้สตาฟทั้ง 8 คน (คนละบัญชี) เลือกสิทธิ์
   - หรือตั้งบัญชีแบบรู้กันเองใน `Code.gs`: แก้รายการ `STAFF_LOGINS` ด้านบนไฟล์ (ชื่อผู้ใช้ / รหัสผ่านอย่างน้อย 8 ตัว / role) แล้วเลือกฟังก์ชัน **`setStaffLogin`** กด Run หรือใช้เมนู ✦ Celestial → ตั้งบัญชีสตาฟตาม STAFF_LOGINS (เปลี่ยนรหัสแล้วรันใหม่ได้ ไม่ต้อง Deploy ใหม่) — ใส่รหัสจริงเฉพาะในหน้า Apps Script เท่านั้น ไฟล์ `backend/Code.gs` ในโฟลเดอร์นี้เว้นรหัสไว้ว่าง
   - **สตาฟ**: แก้เนื้อหาทุกอย่าง อัปเดตอันดับ สถานะ แบนเนอร์ ปฏิทิน กรอกคะแนนโหวตภายนอก ประกาศผลโหวต ดูแลแฟนคลับ
   - **แอดมิน**: ทำได้ทุกอย่าง + จัดการบัญชีทีมงาน + รีเซ็ตคะแนนโหวต
3. ทุกการแก้ไขถูกบันทึกในเมนู **บันทึกการทำงาน** ว่าใครแก้อะไรเมื่อไร

งานที่ทำบ่อย:
- **อัปเดตอันดับ**: เมนู “อันดับเด็กฝึก” → เลือกรอบ → ลากเรียง (หรือกด “เรียงตามผลโหวตรวม” = โหวตบนเว็บ + คะแนนช่องทางอื่นของรอบนั้น) → ตั้งเส้นตัด → **บันทึกอันดับ**
- **เปลี่ยนสถานะเด็กฝึก** (ตกรอบ/ถอนตัว/เดบิวต์): เมนู “เด็กฝึก” เลือกจากช่องสถานะในแต่ละแถว
- **เพิ่มแบนเนอร์**: เมนู “แบนเนอร์” → อัปโหลดรูป 2100×800 (หรือไม่ใส่รูป ระบบสร้างแบนเนอร์ลายดวงจันทร์ให้)
- **เปิด/ปิดโหวต**: แดชบอร์ด หรือเมนู “ระบบโหวต & ประกาศผล” — เมื่อเริ่มรอบใหม่ ให้เปลี่ยน “นับคะแนนเข้ารอบ” คะแนนจะเริ่มนับใหม่โดยไม่ลบของเก่า
- **กรอกคะแนนโหวตภายนอก + ประกาศผล**: ดูข้อ 7
- **ดูแลแฟนคลับ**: เมนู “แฟนคลับ” → ปุ่ม “จัดการ” → ล้างรูปโปรไฟล์/ภาพพื้นหลัง/ข้อความที่ไม่เหมาะสม เพิ่ม-ลดแต้มใจโบนัส (เช่น รางวัลกิจกรรมแฟนคลับ) หรือระงับบัญชี
- **ระดับแฟนคลับ**: เมนู “ระดับแฟนคลับ & การ์ด” → แก้ชื่อระดับ แต้มขั้นต่ำ สี และแบบกรอบการ์ด (มี 6 แบบ) ดูตัวอย่างการ์ดได้ในหน้าเดียวกัน
- **ประกาศ popup**: “ตั้งค่าเว็บไซต์ → ประกาศ popup หน้าแรก” (แก้ข้อความแล้วจะเด้งให้ทุกคนเห็นใหม่)

## 6. รูปภาพและไฟล์เสียง

- กด **อัปโหลด** ในหลังบ้านได้เลย ไฟล์จะไปอยู่ใน Google Drive โฟลเดอร์ `Celestial Uploads` (รูปแฟนคลับอยู่ในโฟลเดอร์ย่อย `Fan Uploads`) และเปิดแชร์ให้อัตโนมัติ
- **รูปจาก Drive ไม่ขึ้น (แก้แล้วในเวอร์ชันนี้)**: ลิงก์รูปตรงของ Google Drive (`lh3.googleusercontent.com`, `drive.google.com/thumbnail`) ไม่ใช่บริการทางการของ Google และบางครั้งตอบ 403 ทำให้รูปไม่ขึ้น ตอนนี้หน้าเว็บจะลองลิงก์ตรงก่อน ถ้าเปิดไม่ได้จะขอรูปผ่าน Apps Script ของเว็บเอง (`?action=image` ส่งทีละหลายรูปในคำขอเดียว) แล้วเก็บไว้ในเครื่องผู้ชม ครั้งต่อไปขึ้นทันที — รูปที่เคยอัปโหลดไว้แล้วไม่ต้องอัปโหลดใหม่ แค่อัปเดต `Code.gs` ตามข้อ 3.1
  - สคริปต์ยอมส่งเฉพาะรูปที่ใช้อยู่บนเว็บ หรือรูปในโฟลเดอร์อัปโหลดของเว็บเท่านั้น (ไม่เปิดไฟล์อื่นใน Drive)
  - รูปที่อัปโหลดจากหลังบ้านถูกย่อให้พอดีก่อนส่ง (เช่น โปรไฟล์เด็กฝึกไม่เกิน 1200px) จึงโหลดเร็วขึ้น
- หรือวางลิงก์รูปจากที่อื่น รวมถึงลิงก์แชร์ Google Drive (`https://drive.google.com/file/d/…/view`) ระบบแปลงให้เอง — ไฟล์ต้องตั้งค่าแชร์เป็น **ทุกคนที่มีลิงก์**
- เพลงในเพลย์ลิสต์: กดอัปโหลดในหลังบ้าน หรือวางลิงก์ไฟล์ `.mp3` ใน Google Drive หรือใส่ลิงก์ YouTube
  - Google Drive ไม่ยอมให้เว็บอื่นเล่นไฟล์ผ่านลิงก์ตรงแล้ว (ตั้งแต่ปี 2024) เว็บนี้จึงดึงไฟล์เสียงผ่าน Apps Script (`?action=audio`) แล้วเล่นในเครื่อง ครั้งแรกที่กดเล่นจะรอโหลดไม่กี่วินาที
  - สคริปต์ยอมส่งเฉพาะไฟล์ที่อยู่ในเพลย์ลิสต์ ไฟล์ต้องเป็นไฟล์เสียงไม่เกิน 25MB และอยู่ใน Drive ของบัญชีที่ตั้ง Apps Script หรือแชร์แบบ “ทุกคนที่มีลิงก์”
  - อยากให้เริ่มเล่นเร็วที่สุด: วางไฟล์ `.mp3` ไว้ในโฟลเดอร์ `assets/audio/` ของ repo แล้วใส่ลิงก์เป็น `assets/audio/ชื่อไฟล์.mp3`
- ขนาดรูปแนะนำ: โปรไฟล์เด็กฝึก 4:5 (เช่น 800×1000), แบนเนอร์ 21:8, ปกเพลง/ทีมงาน สี่เหลี่ยมจัตุรัส

## 7. ระบบโหวตทำงานอย่างไร

**ผลโหวตเป็นความลับ** — หน้าเว็บไม่แสดงคะแนนหรือเปอร์เซ็นต์ระหว่างโหวต (ข้อมูลคะแนนไม่ถูกส่งไปที่เบราว์เซอร์เลย) ทีมงานเห็นคนเดียวในหลังบ้าน

**คะแนนจากช่องทางภายนอก + ประกาศผลรายรอบ** (หลังบ้าน → “ระบบโหวต & ประกาศผล”)
1. เลือกรอบในการ์ด “คะแนนโหวตรวม” — คอลัมน์ “โหวตบนเว็บ” นับให้อัตโนมัติ
2. กด **+ เพิ่มช่องทางคะแนนภายนอก** ตั้งชื่อ (เช่น Facebook Poll, X, Google Form) จะได้คอลัมน์ใหม่ให้กรอกคะแนนของเด็กฝึกแต่ละคน
   - ปุ่ม ⎘ ข้างชื่อช่องทาง = วางคะแนนทั้งคอลัมน์จาก Google Sheets/Excel (บรรทัดละคน: รหัสหรือชื่อเด็กฝึก แล้วตามด้วยคะแนน)
3. กด **บันทึกคะแนน** (ยังไม่มีใครเห็น)
4. การ์ด “ประกาศผลโหวต” → เลือกว่าจะแสดงตัวเลขคะแนนหรือแค่เปอร์เซ็นต์ และจะแยกคะแนนเว็บ/แต่ละช่องทางหรือไม่ → กด **ประกาศผลรอบนี้**
   - ระบบรวม “โหวตบนเว็บ + ทุกช่องทาง” ณ ตอนกด แล้วแสดงที่หน้า VOTE (หัวข้อ “ผลโหวตที่ประกาศแล้ว”) ภายใน 1 นาที
   - แก้คะแนนทีหลังได้ แต่หน้าเว็บจะยังเป็นผลเดิมจนกว่าจะกด **อัปเดตผลที่ประกาศ** / กด **ยกเลิกประกาศ** เพื่อซ่อนกลับได้
   - คะแนนภายนอกเก็บในแท็บ `voteboard` ของชีต (แท็บส่วนตัว ไม่ถูกส่งไปหน้าเว็บ ยกเว้นผลที่ประกาศแล้ว)

- แฟนคลับต้องสมัครบัญชี (ชื่อผู้ใช้ + รหัสผ่าน) ที่ `login.html`
- 1 บัญชีโหวตได้ **วันละ 1 ครั้ง** เลือกเด็กฝึก 1 คน ระบบตัดรอบ **00:00 น. เวลาประเทศไทย** และตรวจสอบที่เซิร์ฟเวอร์ (แก้โค้ดฝั่งเบราว์เซอร์ก็โหวตซ้ำไม่ได้)
- รหัสผ่านเก็บแบบเข้ารหัสทางเดียว (hash + salt) ทีมงานมองไม่เห็นรหัสผ่านของใคร
- ล็อกอินผิดเกิน 8 ครั้ง บัญชีนั้นจะถูกพักการล็อกอิน 15 นาที
- ข้อจำกัด: ระบบป้องกันคนเดียวสร้างหลายบัญชีไม่ได้ 100% ทีมงานใช้เมนู **แฟนคลับ** ตรวจบัญชีที่ผิดปกติและกด **ระงับ** ได้

## 7.1 โปรไฟล์แฟนคลับ / กดใจ / ระดับแฟนคลับ

- แฟนคลับที่สมัครแล้วมีโปรไฟล์ของตัวเองที่ `profile.html` (แชร์ให้คนอื่นดูได้ที่ `profile.html?u=ชื่อผู้ใช้`)
  - ใส่รูปโปรไฟล์ ตั้ง **ภาพพื้นหลัง** (เช่น รูปศิลปินที่ชอบ — จะเป็นพื้นหลังทั้งหน้าโปรไฟล์และบนการ์ดสมาชิก ถ้าไม่ใส่จะใช้รูปเมนแทน) เลือกเมน สีธีม และข้อความแนะนำตัว
  - รูปที่แฟนคลับอัปโหลดถูกย่อในเครื่องก่อนส่ง (โปรไฟล์ 400×400, พื้นหลังไม่เกิน 1600px) ไฟล์เก่าจะถูกย้ายลงถังขยะเมื่อเปลี่ยนรูป จำกัด 15 ครั้ง/วัน/บัญชี
- **แต้มใจ** ได้จาก
  - กดใจเช็กอินประจำวัน +1 (วันละครั้ง ตัดรอบเที่ยงคืนเวลาไทย เหมือนการโหวต)
  - แฟนคลับคนอื่นส่งใจให้ +1 (แต่ละคนส่งใจได้วันละ 1 ใจ ให้ใครก็ได้ยกเว้นตัวเอง)
  - โบนัสที่ทีมงานเพิ่มให้ในหลังบ้าน
- แต้มถึงขั้นต่ำของระดับไหนก็ได้ระดับนั้น ค่าเริ่มต้น 6 ระดับ: STARDUST (0) → COMET (7) → NEBULA (30) → CONSTELLATION (60) → SUPERNOVA (120) → CELESTIAL (200) แต่ละระดับมีกรอบการ์ดของตัวเอง (กระจกเรียบ → ขอบเรืองแสง → ขอบไล่สีมีดาว → โฮโลแกรมเงิน → ทับทิมทองประกาย → CELESTIAL ออโรร่า)
- ทำเนียบแฟนคลับ `fanclub.html` แสดง 36 อันดับแรกตามแต้มใจ + สมาชิกใหม่
- ประวัติการกดใจทุกครั้งอยู่ในแท็บ `hearts` ถ้าแก้แท็บนี้ด้วยมือ ใช้เมนู ✦ Celestial → คำนวณแต้มใจแฟนคลับใหม่
- ข้อจำกัดเดียวกับการโหวต: ป้องกันคนเดียวสร้างหลายบัญชีไม่ได้ 100% ทีมงานระงับบัญชีที่ผิดปกติได้

| ลืมรหัสผ่าน admin | ใน Apps Script เลือกฟังก์ชัน `resetAdminPassword` → Run → ดูรหัสใน Execution log |
| รูปจาก Google Drive ไม่ขึ้น | อัปเดต `Code.gs` เป็นเวอร์ชันนี้แล้ว Deploy เป็น **New version** (หน้าเว็บจะดึงรูปผ่าน Apps Script ให้เอง) — ถ้าเป็นลิงก์ Drive ที่วางเองจากบัญชีอื่น ให้ตั้งแชร์เป็น “ทุกคนที่มีลิงก์” หรืออัปโหลดใหม่ผ่านหลังบ้าน |
| หน้าโหวตไม่แสดงผลโหวต | ตั้งใจให้เป็นแบบนั้น — ผลเป็นความลับจนกว่าจะกด “ประกาศผลรอบนี้” ในหลังบ้าน |
| หน้าโปรไฟล์/ทำเนียบแฟนคลับขึ้น “ไม่รู้จักคำสั่ง” | `Code.gs` บนเซิร์ฟเวอร์ยังเป็นเวอร์ชันเก่า ทำตามข้อ 3.1 |
